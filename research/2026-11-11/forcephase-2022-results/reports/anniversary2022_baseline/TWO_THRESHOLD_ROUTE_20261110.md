# 两阈值相位规则的实际特征开销与预算敏感性

分析人口为 SAT Competition 2022 Anniversary 官方过滤后保留的 4,719 题。求解时间复用 CaDiCaL 3.0.1、seed 0 的 T600 三动作发布矩阵。两阈值策略优先在原资格内以 SCC 非二元需求 >0.10 选 F−，否则在长度资格内以平均子句长度 >5.73 选 F+，余下用 D。原资格分别是归档明文不超过 1.5 MB、变量不超过 100,000 且有二元子句，以及归档明文不超过 3 MB。所有比较保留 4,719 题。

## 大公式扩展

超过 3 MB 的 1,876 道原 D 题跨八个粗结构簇。466 题三动作都超时。逐题免费最优相位上限可救回 71 题，省 90,717 PAR2 秒。现成 GBD 特征只用平均长度、二元比例和纯正/纯负子句比例。统一成本假设按原 604 个 ≥1 MB 的实测提取中四分位较慢的 102.86 MB/CPU 秒，加每次启动 0.05 CPU 秒。全大公式分支在此假设下提取开销约 1,276 CPU 秒。

| 增量方案 | 相对两阈值策略的 PAR2 变化 | 解题变化 |
|---|---:|---:|
| 免费特征，细形态留组 | +0.321% | −6 |
| 免费特征，粗簇留组 | 0.000% | 0 |
| 假设开销，粗簇留组 | +0.032% | 0 |
| 免费直接扩大 5.73 阈值 | +1.001% | −17 |

加最大收益块惩罚的训练规则在免费比较中也放弃所有额外切换。在计费粗簇比较，训练折有时决定提取，留出的公式没有触发切换，仍产生假设开销。直推阈值救回 1 题，丢失 18 题。按冻结门槛，大公式分支未进入特征采集。无大文件下载，新增求解零。

## 预算截断与 F+ 失败回退

同一固定动作在截断到不同 CPU 预算时，继续扣除原计费两阶段特征 CPU。只有已有验证求解时间加特征 CPU 能落进预算才记为解出。

| 总 CPU 预算 | D / 策略解出 | 相对 D 的 PAR2 降幅 | 细结构块 95% 探索区间 |
|---|---:|---:|---:|
| 60 秒 | 2,378 / 2,381 | 0.046% | [−0.162%, +0.252%] |
| 120 秒 | 2,715 / 2,721 | 0.189% | [−0.096%, +0.497%] |
| 300 秒 | 3,086 / 3,100 | 0.535% | [+0.170%, +0.936%] |
| 600 秒 | 3,385 / 3,401 | 0.838% | [+0.333%, +1.470%] |

T600 下，宽度分支的 259 道 F+ 题测试了 11 档 F+ 时间片，若未解则冷启动 D。扣除失败 F+ 片段的全部 CPU 和调度费用。全部细组、粗组和全数据最佳都选择保持完整 F+。这个分支未增加调度。时间结果沿用既有归档的轨迹。

## 从 CNF 直接执行并计费

新入口对缓存明文、gzip 或 xz CNF 做一次有界扫描，得到原 SCC 需求和平均子句长度，然后输出动作和 CaDiCaL flags。构建与调用示例：

```bash
c++ -std=c++17 -O3 src/anniversary2022_baseline/signed_topology.cpp -o phase-extract
python3 -m src.anniversary2022_baseline.route_phase_2022 input.cnf.gz --extractor ./phase-extract
```

指定 `--archived-bytes` 可沿用归档的明文字节数来判断资格，默认使用当前输入的实际明文大小。此次全量复验沿用归档大小。扫描后核对了 2,843 个输入的 GBD 身份，全部成功。大于 3 MB 的 1,876 题直接选 D。4,719 题的动作与冻结回放逐题一致，三种动作的 CLI flags 均通过实际输入核对。

实际选择 CPU **140.68 秒**，覆盖读取、解压、单次解析及选择。实验单独核验身份用 **21.15 CPU 秒**。进程树子进程共 120.25 CPU 秒，父进程和分析 86.14 CPU 秒，墙钟 **60.74 秒**。上面这些账本包含关系见逐题收据，不相加为部署费用。没有运行求解器，求解时间沿用归档。

| 总 CPU 预算 | D / 实测选择后回放解出 | 相对 D 的 PAR2 降幅 | 细结构块 95% 探索区间 |
|---|---:|---:|---:|
| 60 秒 | 2,378 / 2,381 | 0.036% | [−0.172%, +0.242%] |
| 120 秒 | 2,715 / 2,721 | 0.183% | [−0.102%, +0.493%] |
| 300 秒 | 3,086 / 3,100 | **0.531%** | [+0.167%, +0.932%] |
| 600 秒 | 3,385 / 3,401 | **0.836%** | [+0.330%, +1.467%] |

T600 平均 PAR2 **389.263 秒**，D 为 **392.543 秒**。救回 19 道 D 超时题，失去 3 道 D 解出的题。

## 两个阈值都在组外拟合

将高 SCC 选 F−、余下高平均长度选 F+ 的方向固定。两个阈值和启用分支都由训练组决定，计入刚测量的扫描 CPU，允许训练时回退固定 D。

| 留出方式 | 相对 D 的 PAR2 降幅 | 95% 探索区间 | 解出 |
|---|---:|---:|---:|
| 细形态块 | 0.818% | [+0.308%, +1.450%] | 3,401 |
| 八个粗结构簇 | 0.305% | [−0.116%, +0.960%] | 3,390 |

粗簇区间枚举八簇所有重采样计数向量，按组合权重精确取分位，避免 2,000 次抽样在接近零时的随机误差。固定 0.10/5.73 规则在已见人口上的粗簇区间为 [+0.0016%, +2.081%]，两簇贡献绝大部分净收益。真正留出粗簇并重新拟合两个阈值时，区间跨零。证据支持现有 2022 队列的回放收益，跨粗结构的稳定收益仍未验证。
