# 静态特征与聚类的并行分工

2026-11-04。对应主计划 `EXPERIMENT_PLAN.md`。用户已明确授权本聊天agent并行；本文只定义分工，没有运行求解、拟合、独立audit或dryrun。

## 共用冻结输入

协调者唯一写入 `input_manifest.json`：TA附件SHA、角色/等价组清单SHA、T5000计分约定、提取器SHA、10项特征schema、缺失语义和协议commit。各agent/node只读该版本。

- 标签表与特征表分开；CNF提取worker只接收输入SHA、允许的role和提取参数，不接收wall time、赢家或SAT真值。
- 180fit/60feedback保留全人口；192个资源合格开发实例可提取，其他实例在最终预测回退固定相位，不能删出成本分母。
- 原60gate及5355测试命名空间不派发给开发worker。身份字段只用于关联、去重与固定顺序，不是聚类或模型输入。

## 可同时进行的通道

|通道|启动依赖|独占产物|并行边界|
|---|---|---|---|
|A：缓存关联与静态提取|冻结manifest|逐实例特征及费用receipt|按实例拆分，复用相同输入/提取器身份的完成项|
|B：固定相位/选择空间|完整fit标签及计分器冻结|`fit_baseline.json`|不必等待CNF提取；不读feedback/gate|
|C：简单规则/匹配浅树|完整fit特征状态＋fit标签|fit模型、候选JSON及训练receipt|可与k2/k3聚类同时训练；遵守全局两提案/轮额度|
|D2：k=2聚类|完整fit特征状态＋冻结变换定义|k2变换、中心、fit分配、画像|与D3独立；初始化种子固定，不增加k网格|
|D3：k=3聚类|同D2|k3对应产物|与C、D2并行；不把已有相位标签用于分组|
|E：完整feedback评分|候选/变换冻结＋完整feedback特征状态|逐题预测、成本差、覆盖及区间|候选可并行计分，协调者只发布一个完整轮次快照|

“完整特征状态”包括成功、预先资源排除、超限、失败和可用性标记；不是仅成功题凑齐。明确的输入/解析错误须先解决或按冻结失败契约处理，不能伪装零值。

## 实例分片与结果合并

逻辑任务键为 `SHA256(input_sha + extractor_sha + schema_sha + limits_sha)`；角色不改变公式身份，但输出关联必须保持原角色。协调者唯一领取/发布任务，worker仅写自己的临时文件并原子提交receipt。

每条receipt至少含：task_key、input_sha、extractor/schema/limits SHA、role、node_id、CPU/wall、状态、特征值/缺失原因、结果文件SHA。CPU与wall实测，失败费用保留。完成任务按task_key复用；失联不自动重跑，须取得原进程终结证据。

协调者校验manifest覆盖后发布不可变 `static_fit_snapshot.json` 和 `static_feedback_snapshot.json`；分别列出所有父题及状态与成员SHA。agent/node不能覆盖聚合表或互相修改输出目录。

## 必须等待的屏障

1. 聚类的log1p、fit中位数/IQR和填充值只由完整fit特征计算，冻结后才应用feedback。不得用全数据标准化。
2. fit模型可以在feedback提取尚未完成时训练；feedback评分必须等待全60题的成功/缺失/排除状态齐备。不能评分“先完成的若干题”来决定阈值、继续收题或换候选。
3. k2/k3画像先用fit描述，再用冻结中心给feedback分配。反馈偏好只在正式完整轮次评价时返回，不边到达边调整簇。
4. 同轮两个候选的JSON均冻结后，才发布完整反馈给下一轮ICL。并行agent共享同一轮次上限，不各自开4轮或各自追加两提案。
5. gate只能在唯一候选及所有依赖冻结后，由协调者一次评价；聚类agent与提取agent没有开发gate读取权限。

## 资源与关键路径

静态提取遵从每题2CPU秒/8秒墙钟及现有准备内存上限；并发数按真实空闲CPU和内存预留计算。若提取器保留3GiB准备上限，16GiB主机不能假定8个提取器同时满额运行。

本地小树和聚类可由独立agent启动独立进程；BLAS/线程数限制在统一核心额度内，避免“多个agent×多线程”过量订阅。它们不占用服务器已满载的solver槽位。

首份静态报告的关键路径是 `manifest → max(fit/feedback特征补齐, fit基线) → max(规则, k2, k3) → 完整反馈合并`，不是各通道耗时相加。相同输入只提取一次，所有模型读同一快照；聚类只改变候选发现方式，不改变主标签和评价人口。
