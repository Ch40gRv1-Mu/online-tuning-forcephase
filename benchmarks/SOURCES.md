# Benchmark sources

- GBD meta database: https://benchmark-database.de/getdatabase/meta, downloaded 2026-10-18 19:02 UTC,
  SHA-256 `5b8bbc767bc5300cca6a12717fb2d7c8d52ccee24aced4447d71846352744ff3`.
- GBD base (size/feature) database: https://benchmark-database.de/getdatabase/base, downloaded 2026-10-18 19:02 UTC,
  SHA-256 `15a3d19fd23ba72dd7c77b1b86113873f160760fa1c9710e9e5ed6a23ba29d84`.
- Instances: `https://benchmark-database.de/file/<hash>` (xz-compressed, sanitized CNF as used by the SAT Competition).
  Stored outside git at `$FP_DATA/benchmarks/cnf/<hash>.cnf.xz`; checksums of the download and of the decompressed
  CNF plus the DIMACS header are in `checksums.csv` (`scripts/fetch_benchmarks.py`).
- `manifest.csv` / `family_groups.csv`: generated by `scripts/build_manifest.py --gbd <dir with meta.db, base.db>`.
  Columns: GBD hash, family, family_group (alias + isohash merged), result (GBD, used only for post-hoc
  stratification), years, size, pool, split, temporal_tag, url.
- `smoke20.txt`: smoke-test instance list (20 train instances).

To rebuild from scratch:

    mkdir -p $FP_DATA/benchmarks/gbd && cd $FP_DATA/benchmarks/gbd
    curl -L -o meta.db https://benchmark-database.de/getdatabase/meta
    curl -L -o base.db https://benchmark-database.de/getdatabase/base
    sha256sum meta.db base.db    # compare with the values above (GBD is updated over time)
    scripts/build_manifest.py --gbd $FP_DATA/benchmarks/gbd --out benchmarks
    scripts/fetch_benchmarks.py --splits train,val,test,t2026
